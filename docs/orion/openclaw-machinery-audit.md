The fork inherited a large amount of tooling for maintaining OpenClaw itself. None of it was deleted. Orion is the default product; this is the map of what is what.

Categories: **CORE** platform, **PA** personal assistant, **GENERAL-DEV** reusable developer capability, **HEWAR** project-specific, **OC-MAINT** only useful for maintaining OpenClaw, **EXPERIMENTAL**.

| Area                                                                                                                                                                                                                                                                 | Category                                 | Disposition                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/gateway`, `src/agents`, `src/plugins`, `src/state`, `src/security`, `src/cron`, `src/channels`, channel/provider `extensions/*`                                                                                                                                 | CORE / PA                                | Keep.                                                                                                                                                              |
| `src/personal`, `personal/`                                                                                                                                                                                                                                          | PA                                       | Orion-owned.                                                                                                                                                       |
| `src/orion`, `docs/orion`                                                                                                                                                                                                                                            | GENERAL-DEV (Hewar is configuration)     | Orion-owned.                                                                                                                                                       |
| `src/agents/worktrees`, `src/projects`, `extensions/workboard`, `extensions/github`                                                                                                                                                                                  | GENERAL-DEV                              | Reuse candidates for the engine's worktrees/cards/link readers; `src/orion` currently has its own thin git adapter. Converge when the agent-runtime binding lands. |
| `.agents/skills/openclaw-pr-maintainer`, `clawsweeper`, `clawdtributor`, `gitcrawl`, `tag-duplicate-prs-issues`, `openclaw-repair-sweep`, `autoreview`, `deslop`, `test-audit`                                                                                       | OC-MAINT (some patterns are GENERAL-DEV) | Keep as an optional OpenClaw-maintainer profile. Do not load for Orion or Hewar tasks.                                                                             |
| `.agents/skills/release-*`, `openclaw-changelog-update`, `verify-release`, `openclaw-live-updater`, `openclaw-update`, `openclaw-ci-limits`                                                                                                                          | OC-MAINT                                 | Optional profile only.                                                                                                                                             |
| `.agents/skills/openclaw-ghsa-maintainer`, `security-triage`, `openclaw-secret-scanning-maintainer`                                                                                                                                                                  | OC-MAINT                                 | Optional profile only.                                                                                                                                             |
| `.agents/skills/discord-*`, `discrawl`, `slacrawl`, `graincrawl`, `notcrawl`, `parallels-*`, `crabbox`, `telegram-e2e-userbot`, `slack-e2e`, `proof-video`, `claw-score`, `auto-qa`, `openclaw-qa-testing`, `openclaw-docker-e2e-authoring`, `channel-message-flows` | OC-MAINT / EXPERIMENTAL                  | Optional profile only.                                                                                                                                             |

Orion tasks run in project worktrees and do not inherit it.                                                           |
| `skills/gog`                                                                                                                                                                                                                                                         | PA (superseded)                          | Native Google tools in `src/personal` replace it; kept for users who prefer the CLI.                                                                               |

Status: classification only. Moving OC-MAINT skills behind an explicit profile switch is a follow-up that needs the skills loader's profile contract.
